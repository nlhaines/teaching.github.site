Teaching apps

These are browser-based classroom activities I have built and used with students at ILA Vietnam.

Language Learning Suite

A suite of three linked classroom tools for vocabulary and grammar practice:

  1. a teacher-run game platform with multiple game formats and a class scoring system,
  2. a student self-study arcade for independent practice and review,
  3. and a content builder for creating and editing unit materials.

All three tools run from the same lesson content, making it easy to support whole-class activities, student self-study, and ongoing lesson refinement within one system.

  • Classroom tool
  • Student arcade
  • Unit builder (currently unavailable)

Zombie Survival Game

A choose-your-own-adventure reading activity for B1 English learners. Students work through survival scenarios that require reading, vocabulary use, and group decision-making. The game supports movement through an optional sticky-ball throw that can replace the dice-roll mechanic.
